# Dependencies and desktop builds

`go.mod` pins all direct modules, including Fyne v2.8.1 (released; [upstream](https://github.com/fyne-io/fyne/tree/v2.8.1), BSD-3-Clause), `tcell/v3` v3.4.2, `lipgloss/v2` v2.0.5, and notmutt `lib/xdg` and `lib/localipc` v0.1.0. Windows named-pipe I/O uses [Microsoft/go-winio](https://github.com/Microsoft/go-winio) v0.6.2 (MIT): its cancellable `DialPipeContext`, secured `ListenPipe`, and first-instance/remote-rejection behavior replace hand-rolled overlapped Win32 I/O. Its selected graph adds `github.com/sirupsen/logrus` v1.9.3 (MIT). Go 1.26.6 is required. Mihomo is a separately selected executable, not a Go dependency; no core binary is bundled.

Inspect the selected module graph with `go list -m all` and its edges with `go mod graph`. `THIRD_PARTY_LICENSES.txt` contains the license text and notices for every selected module, including Fyne's bundled fonts. The module cache is not vendored. Changes to a direct or transitive pin require a new license/security review, graph comparison, and target build checks. The project maintainer owns upgrades or removal; remove unused dependencies rather than silently changing their versions.

Fyne's native desktop driver requires CGO and platform graphics libraries: Linux needs an X11/OpenGL development toolchain (Mesa, Xcursor, Xrandr, Xinerama, Xi, Xxf86vm); macOS needs Xcode Command Line Tools; Windows needs the runner's MinGW/GCC toolchain. Native builds must run on each target; `CGO_ENABLED=0` cross-compilation of the `ci`-tagged software renderer is not a release build. See [Fyne's cross-compilation guide](https://docs.fyne.io/started/cross-compiling/) and [packaging guide](https://docs.fyne.io/started/packaging/). `.github/workflows/build.yml` runs tagged tests/vet and native desktop builds on Linux, macOS, and Windows; it uploads per-platform build artifacts, not signed releases. Local Linux in this workspace lacks graphics headers, so only `-tags ci` software-renderer tests/vet have been run locally; target-native CI results remain a release gate.
